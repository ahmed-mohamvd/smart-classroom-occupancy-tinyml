# Current Firmware Snapshot

`main_pir_filtered.c` is the latest saved data-collection `main` file. It operates the BME280, BH1750, VL53L0X, OLED, two PIR sensors, buttons, LEDs and buzzer, and outputs one CSV row per second.

This is **not** the final AI-integrated firmware. It does not include the complete `occupancy_ai` runtime integration, so use it as a data-collection and hardware-reference snapshot only.
