# أكواد اختبار الحساسات

هذه الملفات للاختبار المنفصل وتشخيص التوصيلات، وليست البرنامج النهائي.

| الملف | وظيفته |
|---|---|
| `I2C_ADDRESS_SCANNER_ONLY.txt` | يفحص عناوين أجهزة I2C المتصلة |
| `BH1750_OLED_CODE.txt` | اختبار BH1750 مع شاشة OLED على STM32 |
| `NodeMCU_BH1750_Test.ino` | اختبار BH1750 القديم باستخدام Arduino/ESP8266 |
| `VL53L0X_OLED_CODE.txt` | اختبار VL53L0X وعرض المسافة على OLED |
| `vl53l0x_platform_STM32_HAL.c.txt` | طبقة الربط بين مكتبة VL53L0X وSTM32 HAL |
| `VL53L0X_STM32_SETUP.md` | شرح تجهيز مكتبة VL53L0X في مشروع STM32 |
| `FULL_HARDWARE_TEST_WITHOUT_BH1750.txt` | اختبار النظام القديم قبل إضافة BH1750 |

إذا استُبدل VL53L0X لاحقاً بـVL53L1X، لا تستخدم ملفات VL53L0X له؛ الحساس
الجديد يحتاج driver خاصاً به رغم أن العنوان الافتراضي لكليهما `0x29`.
