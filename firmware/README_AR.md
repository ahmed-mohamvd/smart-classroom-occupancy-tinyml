# أكواد STM32 والحساسات

هذا المجلد يجمع ملفات الكود المرجعية فقط. مشروع STM32CubeIDE الكامل موجود
خارج هذا المجلد، لذلك هذه الملفات لا تُبنى مباشرة من هنا.

| المجلد | المحتوى |
|---|---|
| `current` | أحدث نسخة main محفوظة محلياً، وهي نسخة جمع الداتا |
| `sensor_tests` | أكواد اختبار I2C وكل حساس بصورة منفصلة |

عند تعديل المشروع الحقيقي، انسخ الجزء المطلوب داخل مناطق `USER CODE` في
CubeIDE ولا تستبدل ملفات CubeMX المولدة دون مقارنة.
