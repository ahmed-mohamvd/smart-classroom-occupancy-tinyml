# Training Walkthrough Notebook

`training_walkthrough_english.ipynb` presents the model-development process step by step using the project dataset. The notebook includes saved outputs so the results can be reviewed without retraining.

Use `OPEN_TRAINING_NOTEBOOK_ENGLISH.bat` to launch the notebook environment on Windows.

Useful results for presentations include the train/validation/test split, model summary, training history, accuracy/loss curves, confusion matrix and INT8 model size.
