# توثيق المشروع

| المجلد | وظيفته |
|---|---|
| `presentation` | النسخة النهائية من العرض بصيغتي PPTX وPDF |
| `presentation_assets` | صور الأيام والسكربت المستخدم لإنشائها |
| `project_reference` | وثيقة متطلبات/تعريف مشروع التدريب الأصلية |

الملفات هنا للتقرير والعرض وليست جزءاً من Build الخاص بـSTM32 أو تدريب AI.
