# جلسات الإشغال المسماة

أسماء الملفات توضح رقم الجلسة والفئة وحالة المكيف والإضاءة والموقع، مثلاً:

`S21_LOW_ACON_LIGHTON_LOC2_R2.csv`

- `S21`: رقم الجلسة.
- `LOW`: شخص واحد.
- `ACON`: المكيف يعمل.
- `LIGHTON`: الإضاءة تعمل.
- `LOC2`: الموقع الثاني.
- `R2`: إعادة تسجيل.

الجلسات الموجودة هنا هي مصادر `occupancy_training_dataset_v7.csv`.
