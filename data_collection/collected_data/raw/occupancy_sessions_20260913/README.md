# Named Occupancy Sessions

File names encode the session number, occupancy class and operating conditions. For example:

`S21_LOW_ACON_LIGHTON_LOC2_R2.csv`

- `S21` — session number
- `LOW` — low occupancy
- `ACON` — air conditioner on
- `LIGHTON` — lights on
- `LOC2` — second sensor location
- `R2` — second recording

These sessions are source data for `occupancy_training_dataset_v7.csv`.
