# الداتا المنظفة المعتمدة

- `occupancy_training_dataset_v7.csv`: الداتا النهائية المستخدمة في التدريب.
- `occupancy_training_dataset_v7.report.json`: تقرير عدد الصفوف والقص والتحقق.
- `occupancy_training_dataset_v7.rejected.csv`: الصفوف المستبعدة وسبب الاستبعاد.

النسخ v1 إلى v6 وملفات pilot نُقلت إلى الأرشيف لأنها لم تعد النسخة المعتمدة.
