# STM32 TinyML Integration

This folder contains preprocessing and inference helpers for deploying the selected occupancy model on STM32.

## Main Files

- `occupancy_features.c/.h` — maintains the PIR sample window, computes the six features, normalizes them and quantizes to INT8.
- `occupancy_ai.c/.h` — initializes and runs the generated ST.AI network.
- `generated_network/` — reference files generated by STM32Cube.AI / ST Edge AI.

The deployed model is `../ai_module/tensorflow_occupancy/artifacts_pir_v2/occupancy_model_int8.tflite`.

## Reported Deployment Characteristics

- Input: INT8 `[1, 6]`
- Output: INT8 `[1, 3]`
- Network weights: 356 bytes
- Activation RAM: 1,028 bytes
- Compute: 320 MACC per inference
- Host validation agreement between the TFLite model and ST.AI C-model: 100%

The runtime collects PIR samples once per second, performs the first inference after a 30-sample window is available, and then updates every five samples. Output index `0` maps to `EMPTY`, `1` to `LOW`, and `2` to `HIGH`.
